# 方法适用性：现有数据核算与解析反例

本次只读取保存的分数和梯度日志，执行CPU解析计算；没有加载或训练模型，没有用Dev确定训练预算。复算脚本：`experiments/deberta_lexical/check_method_applicability.py`。

## 1. 梯度冲突是真实存在的，但不能据此给出涨分概率

早期BLOOP实验`run25_row_pair_ema_bloop`的870批日志中，723批Row/Pair梯度内积为负，占83.10%，余弦中位数-0.3825。这是3290行、无Lexical的早期配置，不是当前3042行锚定实验的重新测量。

合成梯度与当前Row梯度内积仍为负的有130批，占14.94%。BLOOP投影针对Row梯度EMA，不一定保护当前批次Row；该统计还不是AdamW实际位移。说明梯度冲突方法有使用依据，但“平均梯度保护”不等于所有样本正确。

## 2. 上一条的按类平均CE约束仍不充分

当前锚定实验10轮共40个类别阶段比较中，出现22次类别正确数下降；其中18次伴随该类CE增加，4次没有。例子：

| 阶段 | 该类CE，Row→Pair | 该类正确数，Row→Pair |
| --- | --- | --- |
| 第3轮E | 1.0328→0.9453 | 129→124 |
| 第5轮B | 0.5336→0.4832 | 168→164 |
| 第6轮N | 1.0863→0.9429 | 81→78 |
| 第8轮B | 0.5924→0.5342 | 169→164 |

18/22是回顾性的退化检测率，绝不能表述为约82%的训练涨分成功率。按类均值CE仍可用更多自信的正确预测抵消新增错误。

解析反例：两条金标都是F，金标概率从[0.6,0.6]变为[0.999,0.49]，且第二条N概率为0.508。平均CE从0.5108降到0.3572，正确数从2降到1。零预算的平均CE约束也允许这个退化。

## 3. 当前Pair目标允许“损失更低、单行都错”

以下是按现有Pair权重[1,1,1.25]、label smoothing=0.05构造的解析反例，不是实测模型训练路径。两条金标分别为F、B，列顺序F/B/E/N：

| 状态 | 第一行logits | 第二行logits | 独立预测 | 组合预测 |
| --- | --- | --- | --- | --- |
| 初始 | [3,0,0,2.8] | [0,3,0,2.8] | F/B，全对 | FB，正确 |
| 条件组合概率最优点的一种分解 | [2.3163,0.2861,0.3976,2.8] | [0.2861,2.3163,0.3976,2.8] | N/N，全错 | FB，正确 |

Pair CE（未乘外层0.5）从0.229966降至0.185836，单行平均CE从0.651442升至1.064777。N分数未改变。这一例甚至不需要N被直接推高。

推导：平滑后的目标q=[0.966667,0.016667,0.016667]，乘类别权重并归一化后，最优组合概率为[0.962656,0.016598,0.020747]。因此最优S_FB−S_BF=log(58)=4.060443，S_FB−S_EE=log(58/1.25)=3.837299。在保持每行F/B/E均值为1、两方向对称且N=2.8的分解中，得到表中最优点。脚本验证了概率和损失。

但不能据此重新推荐“关闭平滑”：项目已有同数据对照`run09_pair_no_smoothing`，最佳独立F1=0.805389、结构F1=0.900668，仍未超原0.938配方。平滑是一个影响因素，不是完整根因。

## 5. 比平均CE更贴近问题的保护对象

对本轮Row结束时Train上判对的样本i，定义margin_i=z_y−max(z_其他)，参照下限rho_i=min(1,margin_i^Row)>0；本来判错的行不设保护下限。

```text
damage_i = max(0, rho_i - margin_i_current)  # 仅对原本判对的Train行
```

保护目标可表达为damage_i<=0。逐项损坏非负，不能被另一条样本的改善抵消；原来判错的行仍可学习改善。在固定被测样本上，若这些约束被精确满足，则原来判对的行仍然判对。这是直接数学结果，不依赖Cooper这个名字。

用保存的Dev分数回顾性检查，10轮累计510次“Row对、Pair错”的行事件都产生正damage。510是跨轮累计事件，不是510条不同Dev样本；全部识别是由margin定义保证的，不是训练成功证据。

若实施，只能在Train参考上构造保护；Dev上的同类事件仍可能发生。对damage设置非零平均预算后也会允许少量错误；随机原始—对偶求解不保证每个更新严格满足约束。要声称步级保护，需要在固定训练保护批次上检查实际候选更新。

## 6. 方法适用性判断

| 路线 | 当前判断 |
| --- | --- |
| Cooper＋四类平均CE预算 | 能发现主要类别塌陷，但已有均值抵消反例，不能直接照上一条落地 |
| Cooper或其他求解器＋原本判对样本的margin损坏约束 | 与实际损坏最直接对应，值得先做小规模训练机制验证；它首先防损坏，并不直接保证Dev新增正确数 |
| ConFIG/PCGrad/BLOOP | 冲突确实存在，有相关性；只保护平均梯度，不提供样本正确性或有限AdamW步保证 |
| FAMO/GradNorm/uncertainty weighting | 调整权重/尺度，不能直接识别逐样本margin损坏 |
| SAM/R-Drop/Lookahead/LLRD | 可研究泛化或稳定性，不能单独解决当前缺少判别保护的问题 |
| CRF/structured hinge保留三候选 | 保留不变性，排除为直接解法 |
| 单独关闭Pair平滑 | 已有负对照，不能当新方案重复推荐 |

结论：本次证据支持优先研究“直接保护单行正确样本的margin”，不支持任何候选有80%概率提高Dev F1。防止已有正确样本被破坏、改善未见样本、超过原0.938，是三个不同的验收目标，不能混成一个保证。
